# Идеи развития печати счета

## Что уже есть
В модуле реализована базовая печать `ПечатьСчётаНаОплату(ТабДок, Ссылка)`:
- загрузка макета `ПечатьСчётаНаОплату`;
- запрос шапки документа и строк табличной части `Товары`;
- вывод разделов `Заголовок`, `Шапка`, `ТоварыШапка`, `Товары`, `Подвал`.

## Приоритетные фичи

### 1) Итоги по документу и валюта в подвале
- Добавить поля: итог по количеству, итог по сумме, НДС (если используется), сумма прописью.
- Ценность: счет становится готовым к отправке без ручных дописок.
- Изменения:
  - расширить запрос агрегатами по табличной части;
  - добавить параметры в область `Подвал` макета;
  - вычисление суммы прописью вынести в отдельную функцию модуля.

### 2) Печать реквизитов компании и клиента
- Выводить ИНН/КПП, адрес, телефон, банковские реквизиты продавца и клиента.
- Ценность: более формальный и «боевой» счет для контрагентов.
- Изменения:
  - дополить запрос данными из справочников (организация, контрагент);
  - добавить область `Реквизиты` в макет и заполнение параметров перед таблицей товаров.

### 3) Поддержка скидок и цены до/после скидки
- Для каждой строки показывать скидку (%/сумма) и итоговую цену.
- Ценность: прозрачность расчета для клиента и меньше вопросов менеджерам.
- Изменения:
  - расширить выборку строк (поля скидки);
  - обновить область `Товары` в макете;
  - добавить проверку, чтобы пустые скидки не «засоряли» печатную форму.

### 4) Условия оплаты и срок действия счета
- В печать добавить блок: условия оплаты, срок действия счета, комментарий менеджера.
- Ценность: уменьшение операционных уточнений с клиентом.
- Изменения:
  - хранить параметры в реквизитах документа/константах;
  - выводить отдельной областью перед подвалом.

### 5) Несколько шаблонов печати
- Сделать переключение шаблона: «краткий», «с НДС», «с подписью и печатью».
- Ценность: один документ закрывает разные сценарии (B2B, внутренние, экспорт).
- Изменения:
  - параметр процедуры/команды печати `ВариантМакета`;
  - выбор макета по варианту;
  - fallback на базовый макет.

### 6) Локализация и мультивалютность
- Корректно выводить валюту документа, формат сумм и текст суммы прописью для нужного языка.
- Ценность: можно использовать в международных сделках без ручных правок.
- Изменения:
  - в запрос включить валюту;
  - вынести форматирование в вспомогательные функции;
  - предусмотреть разные подписи колонок (RU/EN).

## Быстрый roadmap внедрения
1. Сначала внедрить итоги, реквизиты и условия оплаты (максимальный эффект при минимальных изменениях).
2. Затем добавить скидки и альтернативные шаблоны.
3. После этого сделать мультивалютность/локализацию.

## Точки расширения в коде
- После `Запрос.Текст` — расширение состава данных.
- Перед `ТабДок.Вывести(ОбластьТоварыШапка);` — вывод доп. блоков (реквизиты/условия).
- Перед `ТабДок.Вывести(Подвал);` — расчет итогов, суммы прописью, валютного форматирования.

## Критерии готовности каждой фичи
- Печать формируется без ошибок на документах с 1 и 100+ строками.
- Макет не «плывет» при пустых необязательных реквизитах.
- Суммы в строках и итогах совпадают с документом 1С.
- Новые поля отключаемы/совместимы с текущей формой.
